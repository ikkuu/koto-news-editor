# Scriptableウィジェット セットアップ手順

iPhoneのホーム画面に To-Do をウィジェットとして表示する手順です。
所要時間：10〜15分。

## ステップ 1: Scriptable をインストール

App Store で **Scriptable** を検索 → インストール（無料）。

開発元は Simon Støvring。レビュー多数で信頼性◎。

## ステップ 2: スクリプトを作成

1. Scriptable を開く
2. 右上の **「+」** をタップ
3. 開いたエディタを長押し → 「すべて選択」→ 削除
4. 以下のURLをPC等で開いてコードをコピー：
   ```
   https://ikkuu.github.io/koto-news-editor/todo/widget.js
   ```
5. Scriptable のエディタにペースト
6. 左上の **「Untitled Script」をタップ** → 名前を **TodoWidget** に変更
7. 右下の ▶ をタップしてプレビュー表示されればOK（中サイズで表示される）

## ステップ 3: ホーム画面にウィジェットを追加

1. iPhone のホーム画面を長押し → 「+」（左上）
2. 検索で **Scriptable** を選択
3. サイズを選ぶ：
   - **Small**：今日の最優先2件のみ
   - **Medium**：今日 + 今週から上位5件（**推奨**）
   - **Large**：全カテゴリの上位2件ずつ
4. **「ウィジェットを追加」** タップ
5. ホーム画面上のウィジェットを長押し → **「Edit Widget」**
6. Script に **TodoWidget** を選択（他項目はそのままでOK）
7. 完成

## 動作確認

- ホーム画面に戻るとウィジェットにTo-Doが表示されているはず
- タップするとSafariで `todo/` ページが開く（チェックはここでつける）
- リスト更新後、すぐ反映したい場合：ウィジェット長押し → **「Refresh」**

## トラブルシュート

| 症状 | 対処 |
|---|---|
| 「読み込み失敗」と表示 | Wi-Fiまたはモバイル通信を確認、URLが正しいか確認 |
| ウィジェットが空白 | スクリプトを実行（Scriptableアプリで▶）してエラー有無を確認 |
| 内容が古い | iOSの仕様で15分〜1時間ごとに更新。即時反映はRefresh |
| 文字が切れる | サイズを大きいものに変更、または項目数を減らす |

## 制約

- iOSの仕様で、ウィジェットからチェックを操作することはできません。チェックはタップで開く `todo/` ページから。
- 自動更新間隔はiOSが制御するため、即時反映はできません（手動Refreshは可能）。
- スクリプト本体（widget.js）の修正があれば、再度コピペが必要です。私が修正したらお知らせします。
